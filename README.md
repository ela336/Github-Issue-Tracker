# 📖 Project Overview

**GitHub Issue Tracker** is a modern and responsive issue management application built with **React.js**. It helps developers and teams efficiently manage project issues by providing issue filtering, search functionality, priority labels, and visual analytics. The application offers an intuitive interface for tracking issue status, improving productivity, and organizing project workflows.

---

# ✨ Key Features

- 📝 Create and manage project issues
- 🔍 Search issues by title
- 📂 Filter issues by **All**, **Open**, and **Closed**
- 🏷️ Priority labels (High, Medium, Low)
- 📊 Interactive issue statistics
- 📱 Fully responsive design
- ⚡ Fast performance with Vite
- 🎨 Clean and modern user interface

# 🚀 Run Locally

### Clone the repository

```bash
git clone https://github.com/ela336/Github-Issue-Tracker.git
```

### Navigate to the project directory

```bash
cd Github-Issue-Tracker
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
